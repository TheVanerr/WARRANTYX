# Eski garanti dosyaları

Yeni WarrantyX programından önceki dosyalar. Hiçbiri silinmedi, yalnız buraya taşındı.

Dosyaların içeriği bir sıra kaymış: her dosyada alfabetik olarak bir önceki dosyanın içeriği duruyor.
Gerçek içerikler:

| Dosya | İçinde duran |
|---|---|
| `PROJECT-OVERVIEW.md` | `.copilot-instructions.md` (Copilot talimatları) |
| `doc.css` | `PROJECT-OVERVIEW.md` |
| `doc.html` | `doc.css` |
| `doc.js` | `doc.html` |
| `garanti.md` | `doc.js` |
| `garantie.md` | `garanti.md` (Türkçe garanti metni) |
| `garantim.js` | `garantie.md` (Almanca garanti metni) |
| `git-commands.txt` | `garantim.js` |
| `image.png` | `git-commands.txt` |
| `index.html` | `image.png` (Dolfin logosu) |
| `kapak.js` | `index.html` |
| `kapak.png` | `kapak.js` |
| `seffaf.png` | `kapak.png` (makine fotoğraf kolajı) |
| `warranty.md` | `seffaf.png` (beyaz sayfa) |

İngilizce garanti metni (`warranty.md`) bu kaymada kaybolmuş. WarrantyX'teki İngilizce metin Türkçe ve Almanca metinden yeniden çevrildi (`codes/metin.js`).

Türkçe ve Almanca metin, Dolfin logosu ve fotoğraf kolajı WarrantyX'e aktarıldı.
